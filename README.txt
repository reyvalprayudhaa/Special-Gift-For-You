WEB GIFT — VERSI ROMANTIS (TANPA QR / TANPA BIRTHDAY)

Cara menjalankan:
1. Extract ZIP ini.
2. Buka foldernya di VS Code.
3. Install extension Live Server jika belum ada.
4. Klik kanan index.html > Open with Live Server.

ALUR WEBSITE:
1. Opening
2. Secret PIN
3. Gift Box
4. Digital Bouquet
5. Letter
6. Memories / Photos
7. Our Song
8. Little Reasons I Love You
9. Final Message
